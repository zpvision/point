# Проверка переноса — 18 октября 2026

Последующее исправление: выбор правовой формы получает доступные варианты из версии сценария backend (включая ООО), а поля ИНН/названия адаптируются к выбранной форме. Первый шаг теперь намеренно отличается от ограничения «только ИП» в визуальном образце. Приведённые ниже сравнения относятся к первоначальному переносу.

Дополнительно подключён автоматический поиск реквизитов через существующий API DaData. Для 10-значного ИНН при выбранном ИП форма сразу объясняет, что нужен 12-значный ИНН, и предлагает проверить форму организации. После этих исправлений прошли все 21 frontend-тест, ESLint и production build. Реальный запрос DaData требует серверного `DADATA_API_KEY`.

Проверена собранная версия Go/PostgreSQL, а не подмена API в рабочем приложении.
